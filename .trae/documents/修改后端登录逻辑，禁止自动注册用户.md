## 修改后端登录逻辑

### 目标
修改登录接口，当遇到表里没有的用户时，不自动注册，返回非法登录错误。

### 修改内容

#### 1. 修改登录接口逻辑
- **文件**：`d:\vote\server\routes\auth.js`
- **修改位置**：第63-69行
- **修改前**：如果用户不存在，自动创建新用户
- **修改后**：如果用户不存在，返回401错误，提示"工号未注册"

#### 2. 具体修改方案
```javascript
// 普通用户登录逻辑
let user = await User.findOne({ where: { employeeId: formattedEmployeeId } });

if (!user) {
  // 如果用户不存在，返回错误
  return res.status(401).json({ message: '工号未注册' });
}
```

### 预期效果
- 当输入不存在的工号时，后端返回401错误，提示"工号未注册"
- 前端会捕获这个错误并显示相应的提示信息
- 系统不再自动创建未注册的用户

### 验证方法
1. 清空用户表（保留root账户）
2. 尝试使用不存在的工号登录
3. 确认系统返回"工号未注册"的错误提示
4. 尝试使用已存在的工号登录
5. 确认登录成功

### 影响范围
- 仅影响登录功能，不影响其他功能模块
- 提高了系统的安全性，防止未授权用户登录
