## 计划步骤

1. **停止所有运行服务**
   - 停止前端开发服务器
   - 停止后端服务器

2. **撤销本地所有更改**
   - 执行 `git checkout .` 命令撤销所有未提交的更改
   - 处理可能的文件占用问题（如数据库文件）

3. **拉取最新Git代码**
   - 执行 `git pull` 命令从远程仓库拉取最新代码

4. **验证同步状态**
   - 检查 `git status` 确认工作树干净
   - 确认代码已与远程仓库同步

## 执行说明
- 所有操作将在项目根目录执行
- 停止服务时会使用现有的命令ID
- 如遇文件占用问题，会先停止相关进程再操作
